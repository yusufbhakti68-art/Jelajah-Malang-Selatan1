Pengambilan Data Website (Web Scraper)

Ambil judul, deskripsi, heading, tautan, dan gambar dari halaman publik untuk ditinjau sebelum digunakan.

Ambil Data Google Maps Tanpa API Key

Scraper berjalan di backend Python menggunakan Playwright untuk membuka halaman publik Google Maps. Tidak perlu Google Maps API key. Isi kata kunci dan wilayah, lalu simpan hasil ke MariaDB.

Ambil Data Google Maps Tanpa API dan Simpan ke MariaDB

Jalankan backend Python di komputer/server yang sama. Data akan diproses di backend lalu disimpan ke tabel MariaDB.

Backend belum diperiksa. Jalankan server Python terlebih dahulu.

Endpoint default: http://127.0.0.1:8000. Token admin harus sama dengan SCRAPER_ADMIN_TOKEN pada file .env. Scraper ini tidak memakai API key. Struktur halaman Google Maps dapat berubah atau membatasi akses; gunakan secara bertanggung jawab dan tinjau ketentuan yang berlaku.

Belum ada proses pengambilan data.
Catatan: URL eksternal hanya dapat diambil jika server mengizinkan akses browser (CORS). Jika gagal, unggah file HTML atau tempel sumber HTML. Gunakan hanya data publik yang boleh digunakan dan patuhi ketentuan situs.
