UPDATE FOTO BACKGROUND PROMO BERANDA

Isi paket:
- index.html
- script.js
- style.css

Fitur:
- Kartu Ekonomi Lokal dan Transportasi Publik dapat memakai foto sebagai background.
- Admin Utama dapat memilih foto melalui menu Admin > Promo Beranda.
- Foto dikompresi otomatis agar ukuran penyimpanan lebih kecil.
- Tombol Hapus foto / gunakan warna mengembalikan kartu ke warna/gradient yang dipilih.
- Teks, tombol, dan pengaturan warna tetap dapat diubah.

Pemasangan:
1. Cadangkan file website lama.
2. Ekstrak ZIP.
3. Timpa index.html, script.js, dan style.css lama dengan file dari ZIP.
4. Buka ulang website dan tekan Ctrl+F5.
5. Login sebagai Admin Utama, buka menu Promo Beranda, pilih foto, lalu klik Simpan Perubahan.

Catatan:
Pengaturan dan foto disimpan di LocalStorage browser, sehingga hanya berlaku pada browser/perangkat yang menyimpan data tersebut. Foto dikompresi ke JPEG dengan sisi maksimum 1400 px. Jika penyimpanan browser penuh, pilih foto yang lebih kecil.
